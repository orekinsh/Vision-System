## ❓ Troubleshooting

**Link not working?**
- Check your internet connection
- Try the HTMLPreview alternative link
- Clear browser cache and retry
- Wait a minute (CDN may be caching)

**App not updating?**
- Add `?v=timestamp` to force refresh
- Check if changes were pushed to GitHub
- Try incognito/private browsing mode

**Slow loading?**
- First load may be slow (CDN caching)
- Subsequent loads will be fast
- Try the RawGit link (has better CDN)

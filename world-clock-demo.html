Viewing Instructions

Currently Running:

  • HTTP Server: http://localhost:8000
  • Main App: http://localhost:8000/world-clock.html
  • This Comparison: http://localhost:8000/world-clock-demo.html

To View in Browser:

  • Desktop: Open http://localhost:8000/world-clock.html
  • Mobile Simulation: Use Chrome DevTools (F12) → Toggle Device Toolbar (Ctrl+Shift+M)
  • Side-by-Side: Open http://localhost:8000/world-clock-demo.html

Chrome DevTools Mobile Testing:

  • Press F12 to open DevTools
  • Press Ctrl+Shift+M (or click device icon) to toggle device toolbar
  • Select device: iPhone 12 Pro, Pixel 5, iPad, etc.
  • Test different screen sizes and orientations

Responsive Breakpoints:

  • Desktop: Multi-column grid layout (> 768px)
  • Tablet: 2-column grid (768px - 1024px)
  • Mobile: Single column stack (< 768px)

Features Visible on Mobile:

  • ✓ Single-column card layout for easy scrolling
